**节点**页列出所有节点，拖动行可以排序，公开页按同样的顺序显示。每行右侧四个按钮：安装、编辑、续费设置、
删除。

## 编辑节点

| 设置 | 说明 |
|---|---|
| 名称 | 公开可见 |
| 分组 | 公开可见，见下文[分组](#分组) |
| 备注 | 只在后台显示 |
| 公开显示 | 关闭后节点只在后台出现，公开页和匿名接口里都没有它 |
| 离线通知 | 掉线超过宽限期时推送，见[通知](/config/notify) |
| 每月额度、计算方式、每月重置日、流量校正 | 见[流量统计](/config/traffic) |

公开页能看到名称、分组、国家、系统与硬件信息、实时状态、可用率、流量、价格和到期日；地址、hostname、
备注和 token 只在后台。

删除节点会连同它的历史数据一起删除，不可恢复。机器上的 agent 要另外卸载，见[卸载](/install/uninstall)。

## 续费与到期

续费设置里填价格、货币、付款周期和到期时间。价格留空或填 0 显示为免费。

在线节点过了到期日会自动续期：hub 把到期日按付款周期往后顺延，直到晚于今天，并推送一条「已自动续期」
通知。

- 是否过了到期日按 hub 所在机器的时区算，hub 每小时巡检一次到期日。Docker 部署没设 `TZ` 时按 UTC 算，
  东八区要到早上 8 点才跨日
- 只顺延在线的节点：离线节点过了到期日，可能真的到期了。离线期间过期、之后又连上的，等到下一轮小时巡检
  才顺延
- 付款周期为「一次性」的不顺延

公开页和面板上的「N 天后到期」「已过期」按**访客浏览器的日期**算，和 hub 的日期可能差一天。到期提醒见
[通知](/config/notify)。

## 地址与国家

地址只在后台的**节点**页显示，公开页只给一个两位的国家代码。

每个节点最多显示两个地址，一个 IPv4、一个 IPv6，都取自 agent 上报的网卡：

- 网卡上有公网地址就显示它。IPv6 避开隐私扩展生成的临时地址和换前缀后已过期的旧地址
- 网卡上只有内网 IPv4（NAT）时，hub 看到的出口地址也会列出来，排在最前
- 网卡上一个地址都没有时（agent 版本太旧，或 hub 和节点在同一个内网），显示 hub 看到的连接来源

地址是 agent 报什么、hub 看到什么，没有手动填写的入口。

国家按 hub 看到的**连接来源地址**查一次（`ipinfo.io`），不看网卡上填的公网地址，所以：

- 网关做了分流或透明代理时，国家按代理出口算
- hub 前面是 Cloudflare 时不用配：hub 在通过 token 校验的 agent 连接上读 Cloudflare 写入的
  `CF-Connecting-IP`
- hub 前面是别家 CDN 或隧道时，按[反向代理](/install/reverse-proxy#3-透传-x-forwarded-proto-和-x-forwarded-for)
  里的 realip 配置换回访客地址
- 查不出、或 hub 访问不了 `ipinfo.io` 时，国家留空，公开页上不显示徽章

## 分组

节点多了以后，公开页可以按分组切换。每个节点设一个分组，在**编辑节点**里填：

- 分组名是**任意文本**，没有长度限制，留空即未分组
- 分组没有单独的列表：**节点**页的筛选下拉和公开页的标签都是从节点身上现取出来的，某台机器改成新名字，
  两边跟着变
- **节点**页工具栏有一个按分组筛选的下拉，用来在后台里挑出某一组；只有还有节点没填分组时，下拉里才会
  多出「未分组」这一项

<Note warn>
  分组名和节点名一样**在公开页可见**。只想自己看的信息写在备注里。
</Note>

### 在公开页上

公开页顶部出现「全部节点」加各个分组的标签，某个分组只有真的被用过才出现：

- 分组的先后跟着节点顺序：拖动节点排序后，每个分组第一次出现的位置就是它的位置，不需要另外排
- 没有分组的节点只出现在「全部节点」下，不会混进任何分组标签
- 一个分组都没有时，标签整行不出现，公开页和没有分组功能时一样
- 顶部的汇总（在线数、流量、实时网速）始终是**全站**的，不随所选分组变化

第三方主题是否按分组显示，由主题自己决定。
