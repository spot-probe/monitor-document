**节点**页列出所有节点，拖动行可以排序，公开页按同样的顺序显示。每行右侧四个按钮：安装、编辑、续费设置、
删除。

## 编辑节点

| 设置 | 说明 |
|---|---|
| 名称 | 公开可见 |
| 分组 | 公开可见，见下文[分组](#分组) |
| 备注 | 只在后台显示 |
| 公开显示 | 关闭后节点只在后台出现，公开页和匿名接口里都没有它 |
| 离线通知 | 掉线超过宽限期时推送，见[通知](/config/notify) |
| 每月额度、计算方式、每月重置日、流量校正 | 见[流量统计](/config/traffic) |

公开页能看到名称、分组、国家、系统与硬件信息、实时状态、可用率、流量、价格和到期日；地址、hostname、
备注和 token 只在后台。

删除节点会连同它的历史数据一起删除，不可恢复。机器上的 agent 要另外卸载，见[卸载](/install/uninstall)。

## 续费与到期

续费设置里填价格、货币、付款周期和到期时间。价格留空或填 0 显示为免费。

在线节点过了到期日会自动续期：hub 把到期日按付款周期往后顺延，直到晚于今天，并推送一条「已自动续期」
通知。

- 是否过了到期日按 hub 所在机器的时区算，hub 每小时巡检一次到期日。Docker 部署没设 `TZ` 时按 UTC 算，
  东八区要到早上 8 点才跨日
- 只顺延在线的节点：离线节点过了到期日，可能真的到期了。离线期间过期、之后又连上的，等到下一轮小时巡检
  才顺延
- 付款周期为「一次性」的不顺延

公开页和面板上的「N 天后到期」「已过期」按**访客浏览器的日期**算，和 hub 的日期可能差一天。到期提醒见
[通知](/config/notify)。

## 地址与国家

地址只在后台的**节点**页显示，公开页只给一个两位的国家代码。

### 显示哪几个地址

每个节点最多显示两个，一个 IPv4、一个 IPv6，取「从外面找得到这台机器」的那一个，每族依次：

1. **手填**的地址（见下文[手动填写](#手动填写)）
2. 网卡上的**公网**地址。agent 上报它的网卡地址，IPv6 避开隐私扩展的临时地址和换前缀后已过期的旧地址
3. hub 看到的**出口地址**——只在同族网卡地址是内网地址时才用（NAT）

第 3 条有两种情况不成立，两种情况都是「hub 看到的地址不代表这台机器」：

- 同族网卡上已经有公网地址：hub 看到的另一个地址是挡在前面的代理的，不显示
- 同族网卡上一个地址都没有：hub 看到的可能是 NAT64、WARP 这类共享转换地址，不显示

一个公网地址都没有时（hub 和节点在同一个内网），显示内网地址——这时它是唯一能把 ssh 送过去的地址。

鼠标停在地址上看它的来源：**手动填写**、**网卡地址**、**hub 看到的出口**（不在节点网卡上）或
**hub 看到的连接地址**。点一下复制。

### 国家码怎么来的

hub 拿节点**自己**的地址查一次 `ipinfo.io`，依次：

1. 网卡上的公网 IPv4
2. 网卡上的公网 IPv6
3. hub 看到的连接来源地址

三者都不公网就**不查**，国家留空——内网地址不发给第三方。IPv4 排在 IPv6 前面，是因为隧道拿到的
IPv6（隧道代理、HE.net 这类）会定位到隧道服务器所在地，不是机器所在地。

所以国家跟着**机器**走，不跟着挡在它前面的东西走：

- 家宽网关做了透明代理或分流，而机器自己有公网地址时，国家按机器算，不再是代理出口的国家
- 反过来，机器只有内网地址（NAT 且没有公网 IPv6）时，才轮到 hub 看到的出口地址说话
- hub 前面是 Cloudflare 或反代时，第 3 条要靠 `X-Forwarded-For` / `CF-Connecting-IP` 才准；这一项
  没配只影响上面那种节点，见[反向代理](/install/reverse-proxy#3-透传-x-forwarded-proto-和-x-forwarded-for)

查出来的国家一直留着，直到节点的查询地址变了才作废。查不出（`ipinfo.io` 访问不了、或那个地址它不
认识）就留空、公开页不显示徽章，并在连接期间重试而不是等下一次重连——每个节点每小时最多一次出站
请求（回到上一个查过的地址时，直接取回那次的结果，不占这个额度）。

### 手动填写

**编辑节点**对话框底部的**地址与地区**有三个可选项：

| 填 | 效果 |
|---|---|
| IPv4 | 替换 IPv4 那一行显示的地址 |
| IPv6 | 替换 IPv6 那一行 |
| 国家/地区 | 替换公开页上的国家代码 |

留空即自动，输入框的提示文字写着当前的自动值（「自动：198.51.100.77」）。手填的值不会被自动更新
覆盖，清空后又回到自动。

- 地址按**本族**校验，并**存成规范形式**（`2409:8A1E:0::0088` 存成 `2409:8a1e::88`）。把 IPv6
  填进 IPv4、或填成 `203.0.113.9:22`（带端口）会报错
- 国家要**两位字母**（`CN`、`US`），大小写随意，存成大写
- 手填的地址只用于显示，hub 不去判断它是否真的可达——所以填一个内网地址也照显，为的是从内网 ssh
- 手填国家后，后台那个徽章带一个「手动指定」的提示；自动查出来的值仍在后台继续更新，清空手填即取回

什么时候该填：

- 机器只有内网地址，查不到国家（hub 与节点同内网，或只有内网 IPv4 又没有公网 IPv6）——填一个国家
- 网卡上有多个公网地址，或不想公开网卡上那一个（隧道地址、临时 IPv6）——填你想公开的那个
- 自动查出来的国家不对，或你想让公开页显示某个特定的地区代码

手动填写只影响**显示**。机器上真正用哪个地址是 agent 的事，面板改不了。

## 分组

节点多了以后，公开页可以按分组切换。每个节点设一个分组，在**编辑节点**里填：

- 分组名是**任意文本**，没有长度限制，留空即未分组
- 分组没有单独的列表：**节点**页的筛选下拉和公开页的标签都是从节点身上现取出来的，某台机器改成新名字，
  两边跟着变
- **节点**页工具栏有一个按分组筛选的下拉，用来在后台里挑出某一组；只有还有节点没填分组时，下拉里才会
  多出「未分组」这一项

<Note warn>
  分组名和节点名一样**在公开页可见**。只想自己看的信息写在备注里。
</Note>

### 在公开页上

公开页顶部出现「全部节点」加各个分组的标签，某个分组只有真的被用过才出现：

- 分组的先后跟着节点顺序：拖动节点排序后，每个分组第一次出现的位置就是它的位置，不需要另外排
- 没有分组的节点只出现在「全部节点」下，不会混进任何分组标签
- 一个分组都没有时，标签整行不出现，公开页和没有分组功能时一样
- 顶部的汇总（在线数、流量、实时网速）始终是**全站**的，不随所选分组变化

第三方主题是否按分组显示，由主题自己决定。
